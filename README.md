# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts for the
AttendX student attendance application. Git and GitHub
are used to manage changes and collaborate with QA engineers.

## Test Scripts

1. login_test.py
   - Tests login validation using sample credentials.
   - Verifies that valid credentials pass the test.

2. attendance_test.py
   - Tests the attendance-marking logic.
   - Verifies that attendance is marked as Present
     for the sample student.

## How to Run
Install Python 3, then execute:

python login_test.py
python attendance_test.py

## Version Control
Git is used for local version control, and GitHub
stores the remote repository.
